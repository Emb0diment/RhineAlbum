# RhineAlbum · 莱茵专辑播放器

基于 **[LBEILC / RhineLabUI](https://github.com/LBEILC/RhineLabUI)** 改作的音乐与小说播放器。

**原作者：LBEILC。** 三维界面、模型、开场动画、基础交互及原创示范配乐来自原项目。本项目在其基础上新增歌单管理、音频播放、音乐来源导入与小说朗读功能，并非原作者发布的官方版本。

原项目以《明日方舟》莱茵生命界面为视觉参考；相关作品名称与角色等权利归各自权利人。原始 MIT 许可及 `Copyright (c) 2026 LBEILC` 完整保留于 [LICENSE](LICENSE)。字体和第三方组件许可见 `public/fonts`、`public/licenses`。上游原始说明存档见 [reference/README-upstream.md](reference/README-upstream.md)。

## 功能

- 每行独立对应一个歌单；长歌单分页展示，首次导入的歌单作为默认。
- 单击槽位仅浏览，不打断当前播放；双击槽位进入详情并播放。底部播放条控制正在播放的歌曲，详情页播放按钮控制所选歌曲。
- 顺序／乱序模式统一用于阵列、曲目列表和上一首／下一首，末页不重复填入开头曲目。
- 本地音乐导入、内嵌标签与封面读取、封面修复和本地持久保存。
- QQ／网易云歌单导入、网易云账号扫码读取歌单、联网搜索与音质选择。
- B 站视频音轨下载，以及公开收藏夹分页读取、多分 P 勾选与批量音频导入。
- Windows 当前播放歌曲识别；TXT／EPUB 小说导入与系统语音朗读。
- 点击画面进入，支持触摸、键盘操作与画质优化。

## 运行

安装 Node.js 22.12 或更高版本，然后在项目目录执行：

```sh
npm ci
npm run build
node serve.mjs
```

打开 <http://127.0.0.1:5174/>。Windows 构建完成后也可双击 `启动播放器.cmd`。

开发时先保持 `node serve.mjs` 运行，再在另一终端执行 `npm run dev`，访问 <http://127.0.0.1:5173/>。

更多操作见 [使用说明.md](使用说明.md)。

## 联网与存储

联网接口不是平台官方授权 SDK，可用性受平台接口变化、登录状态、音质权限和访问限制影响。导入曲目清单不代表每首歌曲都有完整音源；本项目不绕过平台访问权限。B 站搜索可能返回 412，私密收藏夹暂不支持。

音乐文件、歌单和小说保存在当前浏览器；清除站点数据会删除这些内容。下载缓存位于 `.local`，网易云登录凭据仅保留在助手内存，重启助手后需重新登录。请只导入有权使用的内容。

本地助手必须有外网访问权限。所有平台同时连接失败时，请检查网络，并在普通终端重新运行启动脚本。小说朗读依赖系统可用的语音服务。

## 验证

`npm run build` 完成类型检查和发布构建。浏览器回归脚本见 `scripts/check-player.cjs`：开发服务运行后，安装可选测试依赖 `npm install --no-save playwright`，运行 `node scripts/check-player.cjs`。可通过 `CHROME_PATH` 指定已有 Chrome，或先用 `npx playwright install chromium` 安装测试浏览器。

测试在独立浏览器上下文中验证浏览不中断音频、跨歌单控制、末页不重复及乱序一致性，不会操作日常浏览器里的歌单。
