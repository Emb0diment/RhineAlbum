## 对话需求与结果

1. 根据 RhineLabUI 和 B 站展示制作专辑播放器，保留模型、开场、相机移动、竖直提起与归位动画。已基于原工程实现，使用 TypeScript、Three.js、Vite。
2. 优化渲染性能。已加入画质设置、自动优化、超级性能模式、静止帧率控制、模态窗口期间暂停及 3D 释放。
3. 导入 QQ 音乐／网易云歌单；“直接捕获”明确指识别客户端当前播放的歌曲。已接入歌单清单导入和 Windows 媒体会话识别；Windows 服务不可用时存在降级限制。
4. 从 B 站音乐视频下载音频。已支持视频链接、分 P 和音质选择，下载由本地助手处理。
5. 小说播放器明确要求 TXT／EPUB 自动朗读。已实现解析、章节、声音、语速和阅读进度；真实语音合成取决于系统服务，原机器曾返回 synthesis-failed，不能保证所有系统可朗读。
6. 联网找音源及多版本。已实现自动选择一个默认候选、即时多选额外版本并增加独立曲目。无需再按确认按钮。
7. 槽位露出的面必须使用歌曲封面，不能仅替换背景或装饰。已实现共享封面图集、内嵌图片解析及更新封面。
8. 原“特别收藏”位置的箭头改为歌单切换。已实现。
9. 顺序／乱序切换，方便选歌与随机听歌。已实现统一顺序；此次修复末页重复映射和乱序列表编号。
10. 点击提起的歌曲应能查看其信息。现在单击只浏览，不打断正在播放的音频；正在播放时底部播放条继续显示和控制当前播放曲目，详情页“播放此歌曲”控制浏览选中的歌曲。
11. 网易云账号导入。已实现扫码、状态轮询、读取歌单和退出；凭据仅在本地助手内存中，重启助手需重新登录。原对话没有完成用户账号的端到端验证。
12. B 站收藏夹导入。已实现公开收藏夹链接／ID、分页、多视频分 P 勾选、音质与批量导入；私密收藏夹暂不支持。流程通过模拟测试，未用用户实际收藏夹完成验证。
13. 首次导入的歌单设为默认。已实现并验证重载后保留，后续导入不覆盖。
14. 每一行专属一个歌单，双击槽位进入详情并播放。已实现；每页五行，每行八个槽位，长歌单在本行翻页，更多歌单用箭头切换。
15. 开场不用专门按钮，点击画面进入。已实现点击／触摸任意位置进入以及键盘 Enter。
16. 所有联网平台出现 fetch failed。曾确认是启动助手进程的外网权限受限，重启具有联网权限的助手后恢复；真实测试过网易云 320 kbps 音源，浏览器播放进度正常前进。
17. 最新两项修复：播放时单击其他槽位不暂停、不重置、不切歌；歌单列表、阵列、上一首／下一首顺序一致。已完成浏览器回归。
18. 用户要求上传 GitHub 并注明原作者，随后要求将对话内容放到云端以便换设备。本文件就是交接材料；是否已经上传应以远端仓库和提交记录为准。

## 最新交互约定

- 单击：选中、提起、浏览；保留当前音频源、播放时间及系统媒体信息。
- 双击：打开详情并播放第一次点中的槽位，避免抬起后误命中后面的卡片。
- 详情页按钮：若所选歌曲就是当前播放曲目则暂停／继续，否则播放所选歌曲。
- 底部控制与系统媒体控制：针对当前播放队列；浏览其他歌单不改变这条队列。
- 顺序模式：原歌单顺序。乱序模式：使用同一随机序列映射曲目列表、槽位与播放队列。
- 末页余下槽位为空，不用歌单开头的曲目补齐。原模型的循环重复显示已限制为当前页的一组槽位。

## 在新设备运行

安装 Node.js 22.12+ 和 Git，克隆本仓库后执行：

```sh
npm ci
npm run build
node serve.mjs
```

访问 http://127.0.0.1:5174/ 。开发时保持助手运行，在另一终端执行 `npm run dev`，访问 http://127.0.0.1:5173/。

歌单、本地音频、小说和进度保存在浏览器本机 IndexedDB／localStorage，并未随源码同步。换设备需要重新导入，网易云需要重新扫码。GitHub 仓库同步的是源码和本交接文档。

## 核心文件

- src/album-player.ts：播放、浏览、默认歌单、顺序、分页、持久化。
- src/main.ts：界面选择、场景回调、详情与开场。
- src/scene.ts、src/archive-loop.ts、src/album-covers.ts：模型、物理槽位映射、封面与双击。
- src/source-import.ts、src/source-ranking.ts：导入、音源搜索、默认版本与多选。
- src/bili-favorites.ts、server/bili-favorites.mjs：收藏夹读取与下载。
- src/netease-account.ts、server/netease-account.mjs：账号扫码与助手内存会话。
- server/api.mjs、server/providers.mjs、serve.mjs：本地接口、平台取流和服务。
- src/novel-player.ts：小说播放。相关解析实现以源码为准。
- src/startup.ts：点击进入。

## 尚需改进或复核

- 音源搜索的自动默认版本要严格匹配歌名／歌手。当前候选列表可能混入不相干歌曲，应防止用相似结果替换原歌。
- 对于登录／会员／地区限制，明确展示平台返回结果；不能承诺全部歌曲直接播放。原对话里的《散，作鸟兽》未登录时未返回完整音源，B 站搜索曾返回 412。
- 真实网易云账号导入、用户实际 B 站收藏夹、不同系统语音服务还需用户设备验证。
- 复核新的有限分页阵列在长距离拖动、跨页、手机触摸及长歌单下的视觉和交互；保留原模型与动画。
